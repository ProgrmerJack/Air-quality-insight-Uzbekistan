# Outputs Directory

```
outputs/
├── charts/                 # Static PNG exports of the published Datawrapper charts
├── datawrapper_links.md    # Quick-access URLs to the live, interactive charts
├── pm25_daily_means.csv    # Daily mean PM₂.₅ by weekday/weekend
├── pm25_diurnal_profile.csv# Hourly weekday/weekend averages
├── pm25_period_summary.csv # Daypart summaries (means/medians/counts)
└── who_pm25_context.csv    # WHO annual reference values for benchmark context
```

Charts can be regenerated by running `process_air_quality.py`, then republishing via the Datawrapper API and re-exporting updated PNGs (see `charts/`).
